實作組專案貢獻度： 依實際出席期間的工作時數計算，一小時為一權重比。
報告組專案貢獻度： 評估較為寬鬆，非逐字精準計算，使組員成績分佈相對平均。
加班與缺席規則： 自行加班不計入工時。每人允許有一次上課缺席（一天計一次，不論該日授課時數），該缺席時數視為抵免工時。
貢獻度公式與試算工具

個人可計工時

個人可計工時 = 個人應出席總工時 − 抵免工時

個人工時比

個人工時比 = (個人實作工時 / 個人可計工時) × 100%

實作組貢獻度

實作組專案貢獻度 = (個人工時比 / 全組工時比之和) × 85%

報告組貢獻度

報告組專案貢獻度 = (報告貢獻字數 / 報告總字數) × 15%
